# Trades Tracker — журнал сделок

Простой журнал трейдера: записывайте сделки и ордера, смотрите P&L и статистику.
Это один файл `index.html` без сборки, сервера и зависимостей.

## Возможности

- **Сделки**: тикер, рынок (крипто, акции, форекс, фьючерсы…), Long/Short, даты входа и выхода, цены, количество, комиссии, стоп-лосс, тейк-профит, сетап и заметки.
- **Расчёты на лету**: P&L, доходность в %, результат в R (от стопа), размер позиции, риск до стопа, соотношение риск/прибыль.
- **Открытые позиции**: оставьте цену выхода пустой, а когда закроете позицию, допишите её.
- **Статистика**: чистый P&L, винрейт, профит-фактор, матожидание, средняя прибыль и средний убыток, максимальная просадка.
- **Кривая доходности** и результат по тикерам или сетапам.
- **Календарь P&L по дням**: итог каждого дня (по дате закрытия) с цветом по величине результата, итоги недель и месяца. Нажмите на день, и в таблице останутся сделки этого дня.
- **Скриншоты графика** к каждой сделке: кнопка, перетаскивание или вставка из буфера (Ctrl+V). Картинки сжимаются до 1920 px и открываются в просмотрщике.
- **Синхронизация между устройствами** через приватный GitHub Gist (см. ниже).
- **Фильтры и поиск**: статус (открытые, закрытые, прибыльные, убыточные), направление, рынок. Статистика пересчитывается под фильтр.
- **Импорт и экспорт**: JSON (резервная копия) и CSV (для Excel и Google Sheets). Импорт понимает CSV с `,` или `;`.
- Светлая и тёмная тема (по настройкам системы), вёрстка под телефон.

## Как запустить

Откройте `index.html` в браузере, и всё работает.

Опубликовать как сайт через GitHub Pages: **Settings → Pages → Deploy from a branch**, выберите ветку `main` и папку `/ (root)`.
Через минуту журнал будет доступен по адресу `https://<ваш-логин>.github.io/trades-tracker/`.

## Где хранятся данные

Сделки хранятся в `localStorage` вашего браузера, скриншоты — в IndexedDB. Своего сервера у приложения нет.
Без синхронизации данные привязаны к браузеру и устройству. Регулярно делайте резервную копию через **Импорт / экспорт → Скачать JSON** (со скриншотами), а на другом устройстве загружайте её через **Заменить журнал**.

## Синхронизация между устройствами

Журнал можно хранить в приватном [GitHub Gist](https://gist.github.com/) вашего аккаунта:

1. Создайте токен на <https://github.com/settings/personal-access-tokens/new>. В правах аккаунта (Account permissions) добавьте **Gists: Read and write**, другие права не нужны.
2. В приложении нажмите **Синхронизация**, вставьте токен и нажмите **Подключить**. Приложение найдёт gist с файлом `trades-tracker.json` или создаст новый.
3. На втором устройстве вставьте тот же токен.

После каждого изменения журнал синхронизируется сам (и при возвращении на вкладку). Если правки сделаны на двух устройствах, они объединяются: для каждой сделки побеждает последняя правка, удаление побеждает правки, сделанные до него.

Ограничения:
- Скриншоты не синхронизируются, их можно перенести JSON-файлом.
- Токен хранится в браузере. На `*.github.io` все ваши сайты делят одно хранилище, поэтому давайте токену доступ только к Gists и задайте срок действия.
- В предпросмотре на claude.ai синхронизация не работает (он не пускает запросы к GitHub). Используйте сайт на GitHub Pages или открытый локально `index.html`.

При первом запуске показываются примерные сделки. Они удаляются кнопкой «Удалить примеры и начать» или автоматически, когда вы добавите первую свою сделку.

## Формат CSV

Первая строка содержит заголовки. Обязательные поля: `symbol`, `side` (`long`/`short`), `openedAt`, `entry`, `qty`.

```
id,symbol,market,side,openedAt,closedAt,entry,exit,qty,fees,stop,target,setup,notes
,BTCUSDT,Крипто,long,2026-10-01T10:00,2026-10-02T15:30,61250,62480,0.15,7.4,60600,63000,Пробой уровня,
```

Даты записываются в формате `ГГГГ-ММ-ДДTчч:мм`. Если `exit` пустой, сделка считается открытой.
